## 📌 Project Overview

This repository contains the complete custom web platform built for **KFab Infra Project PVT LTD**, a leading heavy steel fabrication and industrial manufacturing enterprise located at **M.I.D.C. Jejuri, Pune, Maharashtra**.

Established in **1998**, KFab Infra has executed over **500+ heavy industrial projects** across India spanning metro & railway infrastructure, sugar mills, cement plants, chemical facilities, and material handling systems.

This digital platform was engineered from the ground up to showcase KFab's manufacturing capabilities, technical specifications, industrial client portfolio, NDT quality standards, and to stream-line B2B client inquiries.

## 🛠️ Key Features Built

- **High-Performance UI/UX**: Designed with a custom industrial dark palette (`#0F172A`), metallic gold accents (`#D4AF37`), smooth scroll animations (Framer Motion), and full mobile responsiveness.
- **Dynamic Industrial Vertical Routing**: Multi-page routing covering Home, About, Services, Service Detail pages, Infrastructure, Quality QA/QC, Clients, Careers, and Contact.
- **Interactive Lead & Quote Pipeline**: Firebase Firestore integration for persistent lead storage paired with EmailJS instant notifications for engineering team leads.
- **Enterprise SEO Architecture**: Dynamic meta tags, OpenGraph protocol, custom JSON-LD schemas (`Organization`, `LocalBusiness`, `Service`), and automated sitemap generation.
- **B2B Legal & QA Standards**: Dynamic compliance pages for NDT testing protocols (Ultrasonic, Radiographic, Magnetic Particle), ISO guidelines, Privacy Policy, and Terms of Service tailored for Indian legal jurisdiction.

## 💻 Tech Stack

| Layer | Technology | Purpose |
|---|---|---|
| **Core Framework** | React 18 + TypeScript | Type-safe, component-driven UI development |
| **Build Tooling** | Vite | Fast HMR and production bundling |
| **Styling & UI** | Tailwind CSS + Framer Motion | Custom industrial dark theme & motion animations |
| **Data Viz** | Recharts | Interactive data charts |
| **Backend / DB** | Firebase Firestore | Cloud database for lead capture & inquiries |
| **Email Gateway** | EmailJS | Instant notifications for incoming quotes |
| **SEO & Meta** | React Helmet Async + Schema.org | Technical SEO & structured schema injection |
| **Hosting** | Vercel Edge Network | Global CDN & SSL termination |
